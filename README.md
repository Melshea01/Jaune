# 🟡 Jaune

> **FR** — Application mobile de suivi de consommation d'alcool, conçue pour encourager une réduction progressive grâce à la gamification.  
> **EN** — A mobile application to track alcohol consumption, designed to encourage gradual reduction through gamification mechanics.

---

## 📖 Présentation / Overview

**FR**  
*Jaune* est un projet développé avec Flutter. L'idée est née d'un constat simple : les outils existants pour réduire sa consommation d'alcool sont souvent austères ou culpabilisants. *Jaune* adopte une approche différente, ludique et bienveillante, en s'appuyant sur des mécaniques de jeu pour motiver l'utilisateur sur le long terme.

**EN**  
*Jaune* is a project built with Flutter. The concept stems from a simple observation: existing tools to reduce alcohol consumption tend to be either austere or guilt-inducing. *Jaune* takes a different, lighter approach — leveraging game mechanics to keep users motivated over time.

## 🚀 Installation

```bash
# Cloner le dépôt / Clone the repository
git clone https://github.com/Melshea01/Jaune.git
cd Jaune

# Installer les dépendances / Install dependencies
flutter pub get

# Lancer l'application / Run the application
flutter run
```

> Prérequis / Requirements: Flutter SDK ≥ 3.x — [flutter.dev](https://flutter.dev)
